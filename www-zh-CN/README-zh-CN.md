# moOde WebUI 简体中文副本

本目录是从 moOde `develop/www` 复制并进行简体中文本地化的独立 WebUI 副本。原始 `www/` 保持不变。

## 使用方式

将此目录中的内容部署到测试设备的 Web 根目录（例如替换测试环境中的 `/var/www`），或将目录重命名为 `www` 后部署。正式替换前请备份原目录，并建议先在测试设备上验证。

## 本地化范围

- 覆盖主播放页面、音乐库、播放队列、网络电台、播放列表、音频信息、快速帮助、仪表板，以及音频、MPD、音乐库、网络、系统、音频渲染器、外围设备、蓝牙、多房间、CamillaDSP、均衡器、Peppy、Radio Cover+ 等配置页面。
- 覆盖常见动态通知、状态信息、表单验证和操作结果提示。
- 使用统一简体中文术语；保留 MPD、ALSA、DAC、DSP、DSD、PCM、I2S、USB、UPnP、AirPlay、RoonBridge、CamillaDSP、Peppy 等行业名称和技术缩写。
- 设备、声卡、输出模式、编码格式、采样率、采样格式等原生下拉菜单选项保持英文原文，避免改变程序值或设备标识。
- 曲目、专辑、艺术家、文件夹、电台名称及其他用户媒体元数据不翻译。
- 翻译仅作用于 DOM 显示文本及少量无副作用的显示属性，不修改后端命令、API 参数、数据库值、服务名称、配置键或设备选项。

## 验收说明

翻译层按页面文本、动态提示和帮助说明建立映射；上游版本新增的字符串、少见错误分支或运行时第三方内容仍可能显示英文。请在实际 moOde 设备上逐页检查显示、按钮操作、配置保存和动态通知。下拉菜单选项及媒体元数据明确排除。
