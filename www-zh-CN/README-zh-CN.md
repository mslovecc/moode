# moOde WebUI 简体中文副本

本目录是从 moOde `develop/www` 原样复制的独立中文 WebUI 副本。原始 `www` 不做任何修改。

## 使用方式

将此目录中的内容部署到设备的 Web 根目录（例如替换测试环境中的 `/var/www`），或将目录重命名为 `www` 后部署。请先备份原目录。

## 本地化约定

- 界面语言：简体中文（zh-CN）。
- 音频术语保留行业通用写法：MPD、ALSA、DAC、DSP、DSD、PCM、I2S、USB、UPnP、AirPlay、Roon 等。
- 设备、声卡、输出模式、编码格式、采样率、采样格式等下拉选项保持原文，不翻译，避免改变设备标识或程序判断值。
- 曲目、专辑、艺术家、文件夹及电台名称属于用户媒体数据，不翻译。
- 翻译层通过 DOM 文本映射工作，不修改后端命令、API 参数、数据库值或服务名称。

## 重要说明

当前版本是第一阶段界面本地化：已覆盖常见导航、播放控制、菜单、弹窗和部分通用配置/帮助文本。moOde 页面包含大量由 PHP、JavaScript 和系统运行状态动态生成的内容；未进入术语映射表的英文文本仍会显示英文。请在实际设备上逐页验收后继续补充术语表。下拉菜单选项及媒体元数据明确排除。
